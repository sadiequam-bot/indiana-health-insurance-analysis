# Indiana Health Insurance Premiums and Deductibles Analysis

## Project Overview
This project examines health insurance premiums and deductibles for Marketplace plans offered in Indiana in 2026. The goal is to explore the relationship between monthly premiums and deductibles and better understand the financial trade-offs individuals face when selecting health insurance coverage.

## Data Sources
The data comes from the Centers for Medicare & Medicaid Services (CMS) 2026 Marketplace Public Use Files, including:
- Rate Public Use File
- Plan Attributes Public Use File
- Benefits and Cost Sharing Public Use File

Source: https://www.cms.gov/marketplace/resources/data/public-use-files

## Methodology
This project uses AI-assisted data analysis to examine Indiana health insurance plans. The analysis involves identifying Indiana plans, matching premium and deductible information, and creating a scatter plot to visualize their relationship.
